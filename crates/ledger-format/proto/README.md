# ledger.control.v2 protobuf contract

Source of truth for the control plane ↔ worker gRPC contract, per
the contract lives with the format spec under `ledger-format`.

- Proto file: `ledger/control/v2/control.proto`
- Package: `ledger.control.v2`
- Service: `ControlPlaneService`

Moved from the repo-root `proto/` directory; the old location is gone.

Rules:

- Append-only within major v2. Never reorder or reuse field numbers.
- Wire-incompatible change requires a major version bump.

Buf CI:

```sh
cd crates/ledger-format && buf lint
buf breaking --against '.git#branch=main,subdir=crates/ledger-format'
```

`buf lint` runs in CI (`control-plane-ci.yml`) on PRs that touch this
directory or the worker. `buf breaking` joins when the Go control-plane
repository lands; there is no second side to compare against yet.

Topology:

The external control plane owns campaigns, queues, leases, attempts, and
task assignment. A worker initiates ONE outbound authenticated session;
the control plane assigns tasks over that session; the worker executes
tasks and uploads results carrying the ExecutionIdentity digest. The
worker hosts no service; `ControlPlaneService` is hosted by the control
plane.

Rust wire codec:

`crates/ledger-worker/src/gen/ledger.control.v2.rs` is the tonic/prost
binding generated from this contract (regenerated by the worker build
script under the `grpc` feature; `protoc` is required for regeneration).
The worker connects as a client only; `tests/cross_boundary.rs` exercises
the session against a fake control plane.
